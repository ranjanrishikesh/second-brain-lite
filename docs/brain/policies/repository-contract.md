# Repository Contract

Second Brain Lite is a Git-native template. The committed repository contains the launcher, instruction entrypoints, policies, workflows, and empty retained directories needed to initialize a new brain.

`AGENTS.md` is the canonical agent instruction file. `CLAUDE.md` is a relative symlink to it. `BRAIN.md` indexes the repository lifecycle and directory roles. The executable `./brain` is the CLI entrypoint.

The template intentionally contains no user knowledge. Retained directories are committed only with their `.gitkeep` sentinels until initialization and normal use add content.
